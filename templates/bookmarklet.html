ติดตั้ง Bookmarklet ครั้งเดียว

Bookmarklet = ลิงก์ใน Bookmark Bar ที่กดแล้วรันโค้ดได้ — อันนี้ใช้กรอกและส่งคะแนนให้อัตโนมัติบนหน้า getscore1.com

Bookmark Bar คืออะไร? เปิดยังไง? expand_more
bookmarks
Bookmark Bar = แถบลายแท่งใต้ช่องที่อยู่ URL (อยู่ระหว่างแถบ tab กับหน้าเว็บ)
keyboard
ถ้ายังไม่เห็น แสดงด้วย Ctrl+Shift+B (Chrome/Edge) หรือเมนู ⋮ → Bookmarks → Show bookmarks bar
mouse
ลากปุ่ม TA Autofill ด้านล่างไปวางบนแถบ Bookmark Bar (ทำครั้งเดียว)
ขั้นตอนการใช้งาน expand_more
looks_one
ลาก TA Autofill ไปวางที่ Bookmark Bar (ทำครั้งเดียว)
looks_two
ล็อกอิน Google บนหน้า getscore1.com ให้เสร็จก่อน (ครั้งแรกเท่านั้น)
looks_3
ในหน้า Submissions กดปุ่ม "ให้คะแนนเว็บ" — เบราว์เซอร์เปิด getscore1.com พร้อมข้อมูลนักศึกษาคนนั้น
looks_4
กดปุ่ม TA Autofill ที่อยู่บน Bookmark Bar — กรอกวิชา/แลป/รหัส/คะแนน และกดบันทึกให้อัตโนมัติ

ลากปุ่มนี้ไปวางที่ Bookmark Bar (ครั้งเดียว)

bookmark_add TA Autofill

ถ้าลากไม่ได้ ให้คลิกขวาที่ปุ่ม → Bookmark link

คัดลอกแล้ว — เปิด Bookmark Manager (Ctrl+Shift+O) → Add new bookmark → วางลิงก์ → Save

extension

ทางเลือก: ติดตั้ง Extension — กดปุ่มเดียว ไม่ต้องใช้ Bookmark

ติดตั้งครั้งเดียวบนเบราว์เซอร์เครื่องนั้น แล้วแค่กดปุ่ม "ให้คะแนนเว็บ" ในหน้า Submissions — เปิดหน้า getscore1 พร้อมกรอกและส่งคะแนนให้อัตโนมัติ
